# Case Real - Análise do SLA e Construção de KPI's Operacionais - Setor de Crédito de uma Cooperativa

# Sobre o projeto

Ao trabalhar no setor de crédito de uma cooperativa, notei que havia uma planilha compartilhada por todo o setor, com anos de informações relativas as propostas de crédito analisadas, preenchida diariamente e compartilhada em tempo real entre todos os analistas.

No final do mês, para apresentar a quantidade de analises realizadas e o prazo médio, a coordenação acessava a planilha, filtrava o período e arrastava o cursor da primeira célula do prazo até a última.

Sem visão completa, sem extrair mais informações, de forma manual.

Com base nesta limitação, criei um dashboard real, na mesma planilha e com as ferramentas que eu tinha em mãos, que extrai mais informações estratégicas e elimina essa atividade manual.

Neste projeto, busquei mapear todo desenvolvimento dessa ideia real, utilizando uma base de dados fictícia.
